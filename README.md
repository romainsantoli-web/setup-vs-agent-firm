## Quick-start

```bash
# 1. Clone
git clone https://github.com/romainsantoli-web/setup-vs-agent-firm
cd setup-vs-agent-firm

# 2. Generate a firm (example: SaaS startup)
bash factory/generate-firm.sh \
  --sector saas \
  --stack typescript \
  --size startup \
  --output ./my-firm

# 3. Install ClawHub skills
bash ./my-firm/scripts/install-skills.sh

# 4. Start the MCP extensions server
cd mcp-openclaw-extensions
python3 -m venv .venv
source .venv/bin/activate
pip install -r requirements.txt
cp .env.example .env          # Edit tokens
bash scripts/start.sh

# 5. Add to VS Code settings.json
# "mcp.servers": {
#   "openclaw-extensions": {
#     "url": "http://127.0.0.1:8012/mcp"
#   }
# }

# 6. Verify
bash scripts/status.sh
```

## CI/CD — OpenClaw PR Review

`.github/workflows/openclaw-review.yml` triggers on every PR:

1. Collects diff (stat + patch, 32KB cap)
2. Starts `mcp-openclaw-extensions` server
3. Invokes Quality department agent via OpenClaw Gateway
4. Posts structured Markdown review as PR comment (upserts on re-run)
5. Always carries: `⚠️ AI review — human validation required before merge`

**Required secrets:**

| Secret | Purpose |
|--------|---------|
| `OPENCLAW_GATEWAY_URL` | WebSocket URL of your Gateway (optional — degrades gracefully) |
| `GITHUB_TOKEN` | Auto-provided by Actions |

## Security

- **GitHub PRs**: always created as drafts with `needs-review` label — never auto-merged
- **Auth**: timing-safe `hmac.compare_digest` on Bearer token (I21)
- **Request cap**: `client_max_size=2MB` on aiohttp (I22)
- **Tool timeout**: `asyncio.wait_for` with configurable `TOOL_TIMEOUT_S` (default 120s) (I23)
- **SQL injection guard**: `table_name` validated by regex `^[a-zA-Z_][a-zA-Z0-9_]{0,127}$` + runtime whitelist (I24)
- **Session ID**: regex pattern `^[a-zA-Z0-9_\-:.]+$` on all session_id fields (I41)
- **Tokens**: masked in all logs via `mask_secret()` — only last 4 chars shown
- **Context cap**: `MAX_CONTEXT_BYTES=32768` — WS payloads never exceed 32KB
- **Fleet persistence**: `~/.openclaw/fleet.json` written atomically (rename from `.tmp`)
- **MCP kwargs**: filtered via `inspect.signature` — no parameter injection
- **Legal/HR/Medical outputs**: always carry "AI-generated, requires human review" disclaimer
- **CI workflow**: `permissions: contents: read, pull-requests: write` — minimal scope
